# Orientações do projeto CoopSun

Leia [CLAUDE.md](CLAUDE.md) antes de alterar este projeto. As regras de domínio,
privacidade e verificação também se aplicam ao Codex e a outros assistentes.

Use o fluxo Sites já configurado para publicação privada e mantenha os dados de
clientes separados do código. O pacote para desenvolvimento é gerado por
`scripts/prepare-claude-workspace.mjs`; não edite seu módulo gerado manualmente.
